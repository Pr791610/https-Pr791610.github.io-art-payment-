## 💳 Payment System (Bankart Integration)

This platform uses a **secure Bankart payment gateway** with modern tokenization:

### 🔐 Security Features
- ✔ PCI-DSS compliant (no card data stored)  
- ✔ Token-based transactions  
- ✔ CVV secure input (iFrame)  
- ✔ 3D Secure ready  
- ✔ Real-time processing  

---

## ⚙️ Payment Flow

1. User enters card details  
2. Card data is securely tokenized via `payment.js`  
3. Token is sent to backend (PHP)  
4. Backend sends transaction request to Bankart API  
5. Payment is processed securely  

---

## 🧩 Technical Stack

- Frontend: HTML + JavaScript (payment.js)  
- Backend: PHP (API integration)  
- Gateway: Bankart Payment API  
- Security: Tokenization + 3D Secure  

---

## 🧾 Transaction Details

- 💱 Currency: EUR  
- 💳 Transaction Type: DEBIT  
- 🔁 Supports recurring & card-on-file (optional)

- ✔ Bankart Merchant Account  
- ✔ Public Integration Key
